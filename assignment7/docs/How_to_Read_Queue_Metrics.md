# 如何从 CloudWatch 图上看 Peak queue depth 和 Time to zero

下面用你提供的 **ApproximateNumberOfMessagesVisible** 截图为例说明。

---

## 1. 这张图在画什么？

- **横轴（X 轴）**：时间（例如 17:35 → 18:35，约 1 小时）
- **纵轴（Y 轴）**：Count，即「当前可见消息数」的数值（可能是实时值或按 1 分钟聚合后的值）
- **蓝色线**：就是「队列里可见消息数」随时间的变化

---

## 2. Peak queue depth（峰值队列深度）—— 怎么看？

**含义**：在这段时间里，队列里**最多**同时有多少条消息在等着被处理。

**怎么看**：
1. 看**整条蓝线的最高点**（整张图里最靠上的那个点）
2. 这个最高点对应的 **Y 轴数值** = Peak queue depth  
3. 这个最高点对应的 **X 轴时间** = 峰值出现的时间

**以你这张图为例**：
- 蓝线从 0 开始，大约在 **18:00 之后**开始上升
- 在 **18:16～18:18** 左右达到**最高**，Y 轴大约在 **0.4** 附近
- 所以可以记：**Peak queue depth ≈ 0.4**（若 Y 轴单位是「条」且是聚合值，实际峰值可能是 1 条左右；若 Y 轴单位是千条，则约 400 条。以图例和 CloudWatch 该指标的说明为准）
- 写报告时：**Peak queue depth = [你看到的最高点的 Y 轴数值]**，并注明单位（条或千条，看 CloudWatch 图例）

**一句话**：整条线最上面的那个点 → 其纵坐标就是 **Peak queue depth**。

---

## 3. Time to zero（队列清零时间）—— 怎么看？

**含义**：从「停止灌入新消息」或「达到峰值」之后，到**队列里可见消息数重新变回 0** 一共用了多长时间。

**怎么看**：
1. 找到蓝线**从高处开始往下降**的那一段
2. 看这条线**什么时候第一次碰到 Y=0**（即图的最底部横线）
3. 「碰到 0 的那个时刻」减去「你停止 Locust 或峰值出现的时刻」= **Time to zero**

**以你这张图为例**：
- 蓝线在 18:16～18:18 到达峰值后，并没有一路降到 0
- 到图结束（约 18:35）时，线还在 **0.35～0.4** 附近，**没有回到 0**
- 所以**仅凭这张图**无法得到 Time to zero，只能写：
  - 「在观测的 1 小时内队列未清零」，或
  - 「Time to zero > 约 20 分钟（从峰值到图末）」

**若要量出 Time to zero**：
- 在 CloudWatch 里把时间范围拉长（例如 **3h** 或 **6h**）
- 等 Locust 停掉、不再有新请求后，继续看同一张图
- 看蓝线**何时从高处降到 0**，从「测试结束/峰值时刻」到「降到 0 的时刻」的时长就是 **Time to zero**

**一句话**：看蓝线**从高往低，第一次碰到 Y=0 的时刻**；从「停止加压」或「峰值时刻」到这一点的时长 = **Time to zero**。若图里一直没碰到 0，就写「未在图中归零」或延长观察时间再量。

---

## 4. 实际操作小结

| 要填的项 | 在图上做什么 |
|----------|----------------|
| **Peak queue depth** | 找蓝线**最高点** → 读该点的 **Y 轴数值** |
| **Time to zero** | 看蓝线**从峰值下降到 Y=0** 用了多久；若图内未归零，则拉长时间范围再观察，或写「> X 分钟」 |

画个示意图（文字版）：

```
Y (Count)
  ^
  |         *  ← 最高点：Peak queue depth = 这个点的 Y 值
  |        / \
  |       /   \___
  |      /        \___
  |_____/             \_____  ← 若这条线碰到底部 (Y=0)，从峰值到这里的时长 = Time to zero
  +-------------------------> 时间 (X)
         ↑               ↑
       峰值时刻      归零时刻（若有）
```

用你这张截图的话：
- **Peak queue depth** = 图中最高点对应的 Y 值（约 0.4，单位以图例为准）
- **Time to zero** = 本图内未归零，需延长观察或写「图中未归零，> 约 20 分钟」
